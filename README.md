# 🧮 Jokenpô v2

Um jogo de Jokenpô (Pedra, Papel e Tesoura) desenvolvido em Python, no qual o jogador enfrenta o computador em uma partida divertida e interativa.

## 🚀 Funcionalidades

- Escolha entre **Pedra, Papel ou Tesoura**.
- O computador realiza uma escolha aleatória.
- Identificação automática do vencedor da rodada.
- Verificação de vitória, derrota ou empate.
- Interação com o jogador pelo terminal.

## 🛠️ Tecnologias utilizadas

- Python 3
- Módulo `random`
- Módulo `time`

## 💻 Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo:

   **Executar**

## 🎯 Objetivo

Projeto desenvolvido para praticar conceitos básicos de Python, como:

- Variáveis e tipos de dados.
- Estruturas condicionais (`if`, `elif` e `else`).
- Estruturas de repetição (`while`).
- Entrada e saída de dados (`input` e `print`).
- Importação e utilização de módulos.
- Geração de valores aleatórios com módulo `random`.
